# Fase 3 — Idear

## Objetivo de la fase

Generar la mayor cantidad posible de ideas para resolver los problemas definidos en la fase anterior, sin
filtrar al principio, y luego priorizar las más prometedoras para definir el alcance del MVP.

## Preguntas guía

- ¿Cómo podríamos resolver [PS-X] de una forma distinta a como se hace hoy?
- ¿Qué soluciones existen en otros sectores con producto perecedero o vivo (flores, alimentos frescos,
  farmacia) que podamos adaptar?
- ¿Qué se puede resolver con lo que ya existe en el esqueleto (permisos, auditoría, archivos, PDF, correo)?
- De todas las ideas, ¿cuáles son deseables, factibles y viables a la vez?

## Entregables esperados

- [`brainstorming.md`](brainstorming.md): ideas por problem statement, con priorización, y síntesis del
  alcance del MVP alineada con las fases de [`../../dominio/modulos.md`](../../dominio/modulos.md).

## Estado

**Por iniciar — supuestos iniciales.** Existe un primer borrador de ideas priorizadas para PS-1 a PS-6 y una
propuesta de alcance del MVP. La priorización debe revisarse con el dueño después de las entrevistas.
