# Prototipos

Flujos, bocetos y wireframes generados a partir de las ideas priorizadas en
[`03-idear/`](../../03-idear/brainstorming.md).

Sugerencia de organización: un archivo por flujo prototipado; si más adelante se hacen mockups gráficos
(Figma u otra herramienta), enlazarlos desde el archivo del flujo correspondiente.

## Flujos actuales

1. [`flujo-01-recepcion-importacion.md`](flujo-01-recepcion-importacion.md) — desde que el vuelo de una
   importación llega, hasta que los lotes quedan en cuarentena y el reclamo DOA está listo.
2. [`flujo-02-proforma-y-despacho-exportacion.md`](flujo-02-proforma-y-despacho-exportacion.md) — desde la
   lista de disponibilidad hasta el despacho con salida de inventario y envío de documentos al cliente.

Son prototipos **conceptuales** (diagrama de flujo + boceto textual de pantallas), basados en supuestos.
Sirven para conversar con el negocio y como insumo para wireframes.
