# Fase 4 — Prototipar

## Objetivo de la fase

Convertir las ideas priorizadas en representaciones tangibles y de bajo costo (flujos, bocetos de pantallas,
wireframes) que se puedan mostrar al dueño y al equipo antes de construir los módulos.

## Preguntas guía

- ¿Cuál es la versión más simple de esta idea que ya se pueda mostrar o probar?
- ¿Qué pasos y pantallas necesita cada persona para completar la tarea clave?
- ¿En qué dispositivo y en qué lugar se hace cada paso (bodega con celular, oficina con computador)?
- ¿Qué partes del flujo todavía dependen de supuestos sin validar?

## Entregables esperados

- Flujos conceptuales con bocetos textuales de pantallas en [`prototipos/`](prototipos/README.md):
  - Flujo 1: recepción de una importación (PS-4, PS-3, PS-1).
  - Flujo 2: proforma y despacho de una exportación (PS-5, PS-6).

## Estado

**Por iniciar — supuestos iniciales.** Los 2 flujos tienen un primer borrador conceptual (diagrama + boceto
de pantallas), construido sobre las reglas de [`../../dominio/`](../../dominio/modulos.md). Siguiente paso:
revisarlos con el dueño y el encargado de bodega y, si se confirman, pasarlos a wireframes navegables.

Siguiente fase: 5 (Testear) — ver [`../05-testear/`](../05-testear/README.md).
