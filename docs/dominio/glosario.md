# Glosario de negocio — JR Tropical Fish

Términos del negocio de comercio de peces ornamentales vivos, en orden alfabético. Sirve como lenguaje común
entre el negocio y el equipo de desarrollo: los nombres de entidades, pantallas y reportes deben usar estos
términos.

> Los ítems marcados **(por validar)** son supuestos, en especial los regulatorios (autoridades, permisos y
> trámites en Colombia). No deben tomarse como requisitos legales confirmados hasta validarlos con el negocio,
> su agente de aduanas y/o su asesor legal.

| Término | Definición |
|---|---|
| **Aclimatación** | Proceso de adaptar gradualmente los peces recién llegados a la temperatura y química del agua del tanque destino, para reducir el estrés y la mortalidad. |
| **Acta de recepción** | Documento (PDF generado por el sistema) que deja constancia de lo recibido en una importación: cajas, cantidades vivas, DOA, faltantes y sobrantes por línea, con quién recibió y cuándo. |
| **Acuario** | Ver *Tanque*. En el sistema se usa *tanque* como término genérico para cualquier contenedor de agua con peces. |
| **Agente de aduanas** | Tercero autorizado que realiza los trámites de nacionalización o exportación ante la autoridad aduanera. En Colombia, figura de agencia de aduanas ante la DIAN **(por validar)**. |
| **Agente de carga (freight forwarder)** | Tercero que gestiona el espacio en la aerolínea, emite o tramita la guía aérea y coordina la entrega/recogida en el aeropuerto. |
| **Ajuste de inventario** | Movimiento que corrige el stock cuando la cantidad física difiere de la registrada (por conteo, error de registro, etc.). Lo registra un usuario y lo aprueba otro con permiso para ello. |
| **AUNAP** | Autoridad Nacional de Acuicultura y Pesca de Colombia. Posible autoridad para permisos de comercialización de recursos hidrobiológicos y peces ornamentales **(por validar)**. |
| **AWB / Guía aérea** | *Air Waybill*. Documento de transporte aéreo que ampara el envío; su número identifica el embarque ante la aerolínea. Puede haber guía master (MAWB) y guía hija (HAWB) cuando hay consolidación. |
| **Bodega** | Instalación física donde están los tanques. Una empresa puede tener una o varias bodegas; cada una agrupa ubicaciones. |
| **Bolsa** | Bolsa plástica con agua y oxígeno donde se empacan los peces para el transporte. Varias bolsas van dentro de una caja. |
| **Caja** | Unidad de empaque del envío aéreo (usualmente caja de icopor dentro de caja de cartón). Tiene número, dimensiones, peso bruto y contiene una o varias bolsas. |
| **Catálogo / maestro** | Datos de referencia que usan los demás módulos: especies, tallas, tanques, proveedores, clientes, causas de mortalidad, conceptos de costo, etc. |
| **Certificado sanitario / zoosanitario** | Documento oficial que certifica el estado sanitario de los animales exportados o importados. En Colombia posiblemente expedido o avalado por el ICA **(por validar)**. |
| **CIF** | Incoterm *Cost, Insurance and Freight*: el vendedor paga costo, seguro y flete hasta el destino. Técnicamente marítimo, pero se usa coloquialmente en el comercio aéreo de peces. Ver *Incoterm*. |
| **CITES** | Convención sobre el Comercio Internacional de Especies Amenazadas de Fauna y Flora Silvestres. Ciertas especies (según su apéndice I, II o III) requieren permiso CITES de exportación y/o importación. |
| **Claim / Reclamo** | Solicitud de compensación por peces muertos a la llegada (DOA), faltantes o especie/talla errada. Se hace al proveedor (importación) o la recibe la empresa del cliente (exportación). |
| **Cliente** | Comprador de peces. En exportación, usualmente un importador mayorista del exterior; también puede haber clientes locales (venta local). |
| **Conteo físico** | Verificación manual de la cantidad real de peces en uno o varios tanques. Las diferencias contra el sistema generan ajustes que requieren aprobación. |
| **Costo landed (costo puesto en bodega)** | Costo unitario real de un pez importado: valor FOB más flete, seguros, aranceles, agencia, tasas y demás costos de nacionalización, prorrateados entre las unidades vivas recibidas. |
| **Cuarentena** | Periodo de aislamiento y observación de un lote recién ingresado antes de poder venderlo. Un lote en cuarentena no se puede reservar ni vender. |
| **Densidad por bolsa** | Cantidad máxima de peces de una especie y talla que se pueden empacar en una bolsa sin poner en riesgo su supervivencia durante el viaje. |
| **DIAN** | Dirección de Impuestos y Aduanas Nacionales de Colombia. Autoridad aduanera y tributaria (declaraciones de importación/exportación, facturación electrónica) **(por validar alcance)**. |
| **Disponibilidad (lista de)** | Listado de especies y tallas disponibles para la venta, con cantidades y precios, que se envía a los clientes (en inglés, *stock list* o *availability list*). |
| **DOA** | *Dead On Arrival*. Peces que llegan muertos al destino. Se registran en la recepción (importación) o los reporta el cliente (exportación) y son base para un reclamo. |
| **Embarque** | Envío físico asociado a una guía aérea. Una orden de compra o un pedido puede viajar en uno o varios embarques. |
| **Especie** | Tipo de pez comercializado. Se identifica por **nombre científico** (p. ej. *Paracheirodon axelrodi*), que es el dato único y el que usan CITES y los certificados, y por uno o varios **nombres comunes** (p. ej. "cardenal", *cardinal tetra*). |
| **Estanque** | Contenedor de agua de mayor tamaño, usualmente en tierra o exterior, para producción o mantenimiento. En el sistema es un tipo de *tanque*. |
| **Existencia** | Cantidad de peces de un lote en un tanque específico. Es el nivel más fino del stock. |
| **Factura comercial** | *Commercial invoice*. Documento de venta internacional con cliente, líneas, cantidades, precios, incoterm y total. El sistema la genera en PDF; su relación con la factura electrónica DIAN está **por validar**. |
| **Familia** | Agrupación taxonómica de especies (p. ej. Characidae, Cichlidae, Loricariidae). Se usa para filtrar, agrupar reportes y parámetros por defecto. |
| **FOB** | Incoterm *Free On Board*: el precio incluye la mercancía puesta a bordo en origen; flete y seguro corren por cuenta del comprador. En el negocio de peces se usa como "precio en aeropuerto de origen". |
| **ICA** | Instituto Colombiano Agropecuario. Posible autoridad sanitaria para inspección y certificación zoosanitaria de importaciones y exportaciones de animales vivos **(por validar)**. |
| **Incoterm** | Término de comercio internacional (Cámara de Comercio Internacional) que define quién paga qué y dónde se transfiere el riesgo. En aéreo los formalmente aplicables son EXW, FCA, CPT, CIP, DAP; en la práctica se habla de FOB y CIF. |
| **Lote** | Grupo de peces de una misma especie y talla con un mismo origen (una línea de una importación, una cosecha de producción propia, una compra local). Tiene costo unitario, fecha de ingreso y estado (cuarentena, disponible, bloqueado, agotado). |
| **Merma** | Disminución de stock no vendida. Incluye mortalidad y diferencias de conteo. |
| **Mortalidad** | Muerte de peces en la bodega. Se registra como un movimiento de salida con causa obligatoria (enfermedad, estrés, calidad de agua, depredación, salto, desconocida, etc.). |
| **Movimiento de inventario** | Registro inmutable de un cambio de stock: entrada, salida, traslado, ajuste, mortalidad, cambio de estado o reclasificación de talla. El saldo es siempre la suma de los movimientos. |
| **Nacionalización** | Conjunto de trámites aduaneros y sanitarios para que la mercancía importada quede en libre disposición en el país, con el pago de los tributos correspondientes. |
| **Orden de compra (OC)** | Documento con el que la empresa solicita peces a un proveedor del exterior: especies, tallas, cantidades, precios, incoterm y fecha estimada de embarque. |
| **Packing list** | Lista de empaque: detalle por caja de qué especies, tallas, cantidades y bolsas contiene, con pesos. La exige la aerolínea, la aduana y el cliente. |
| **Peso cobrable** | Peso por el que cobra la aerolínea: el mayor entre el peso bruto y el peso volumétrico de las cajas (factor de conversión **por validar** con el agente de carga). |
| **Producción propia** | Peces reproducidos o levantados por la misma empresa. Ingresan al inventario como lotes con origen "producción propia" **(por validar si aplica)**. |
| **Proforma** | Cotización formal (PDF) que se envía al cliente con líneas, precios, incoterm, condiciones de pago y validez. Al confirmarla se reserva el stock. |
| **Prorrateo** | Reparto de los costos de una importación (flete, aranceles, agencia, etc.) entre sus líneas, según una base: valor FOB, cantidad de piezas o cajas. |
| **Proveedor** | Exportador del exterior (o acopiador local, **por validar**) que vende peces a la empresa. Tiene condiciones propias: moneda, incoterm, ventana de reclamo DOA. |
| **Reclasificación de talla** | Cambio de talla de un lote porque los peces crecieron. Se registra como movimiento y conserva el lote y su costo. |
| **Reserva** | Cantidad de un lote disponible apartada para un pedido de exportación confirmado. Reduce lo disponible para vender, pero no el stock físico. |
| **Stock disponible** | Unidades de lotes en estado *disponible* menos las reservadas. Es lo único que se puede ofrecer y vender. |
| **Talla** | Tamaño comercial del pez. Puede ser una escala (XS, S, M, L, XL) o un rango en centímetros; la escala exacta por especie está **por validar**. Junto con la especie define el producto vendible. |
| **Tanque** | Contenedor de agua donde viven los peces (acuario, tanque o estanque). Es la ubicación física mínima del inventario. Tiene tipo (cuarentena, venta, producción, hospital, empaque) y bodega. |
| **Traslado** | Movimiento de peces de un tanque a otro, sin cambiar el lote ni el stock total. |
| **TRM** | Tasa Representativa del Mercado (COP/USD) certificada en Colombia. Se usa para convertir costos y ventas en dólares; qué fecha de TRM aplicar está **por validar**. |
| **Ubicación** | Lugar donde está físicamente el stock: bodega y tanque. También existen ubicaciones lógicas, como "zona de empaque/despacho". |
| **Venta local** | Venta a un cliente nacional, sin proceso de exportación. Genera una salida de inventario **(por validar si está en alcance)**. |
| **Ventana de reclamo** | Plazo (en horas desde la llegada del vuelo) dentro del cual se puede reclamar un DOA. Se configura por proveedor y por cliente. |
| **VUCE** | Ventanilla Única de Comercio Exterior de Colombia, plataforma para trámites de permisos previos de importación/exportación **(por validar si aplica)**. |
